Esta página no habla directamente con Claude. Claude usa un servidor MCP (en Render o en tu computadora) y esta pestaña se conecta a él por un puente WebSocket. Solo se ejecutan las funciones listadas abajo. El código de emparejamiento vive solo en memoria mientras la pestaña está abierta.
Herramientas para Claude
Cómo conectar

Desde el celular (servidor remoto):

  1. Sube server.mjs y package.json a Render. Variable PLAYGROUND_USERS = nombre=código,otro=código2 (un código distinto por persona).
  2. En Claude: Conectores → Agregar conector personalizado → https://TU-SERVIDOR.onrender.com/mcp/TU-CODIGO.
  3. Aquí arriba: wss://TU-SERVIDOR.onrender.com/bridge + tu código → Conectar.
  4. Usa pantalla dividida (Chrome + Claude). Si se corta, se reconecta sola.
