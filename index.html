Claude MCP

Playground MCP
Estado: No conectado
Esta página no habla directamente con Claude. Claude usa un servidor MCP externo (corre en tu computadora) que abre un puente WebSocket local. Esta pestaña se conecta a ese puente y solo ejecuta las funciones de PlaygroundAPI listadas abajo. No se guarda ninguna clave en el navegador: el código de emparejamiento vive solo en memoria mientras la pestaña esté abierta.
Funciones expuestas
Cómo conectar

Desde el celular (servidor remoto):

  1. Sube server.mjs y package.json a Render con la variable PLAYGROUND_TOKEN (tu código secreto).
  2. En la app de Claude: Conectores → Agregar conector personalizado → URL https://TU-SERVIDOR.onrender.com/mcp/TU-CODIGO.
  3. Aquí arriba escribe wss://TU-SERVIDOR.onrender.com/bridge y tu código, y pulsa Conectar.
  4. Usa pantalla dividida (Chrome + Claude) para que esta pestaña siga activa. Si se corta, se reconecta sola.

Desde una computadora (servidor local):

  1. Registra playground-mcp-server.mjs en Claude Code o Claude Desktop con PLAYGROUND_TOKEN.
  2. Abre este Playground en esa computadora, usa ws://127.0.0.1:8787 y tu código, y pulsa Conectar.
